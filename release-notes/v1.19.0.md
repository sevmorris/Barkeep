**Added**
- **Remove from Brewfile asks what happens to a package that's still installed.** Taking a package out of the Brewfile used to leave it installed, so Homebrew went on upgrading it. Now, when Homebrew has it installed, Barkeep asks first: **Remove and Uninstall**, **Remove and Keep the App Outside Homebrew**, or **Remove from Brewfile Only**. Packages that aren't installed, and taps, are removed straight away as before.
- **Keep the App Outside Homebrew.** For an app you update yourself, Barkeep deletes Homebrew's record of the cask and leaves the app in Applications, so Homebrew stops offering upgrades for it. Without this, an app updated by hand stays on Homebrew's list as out of date, because Homebrew's record still names the old version. It's offered only for a cask that installs nothing but apps and links to programs inside them, such as Calibre's `ebook-convert`, so nothing it installed stops working. **Adopt** hands the app back to Homebrew.

**Changed**
- **Ignore says what it doesn't do.** Its note now says that Homebrew keeps an ignored package installed and goes on upgrading it, since `~/.mrk/sync-ignore` only stops sync offering it.
