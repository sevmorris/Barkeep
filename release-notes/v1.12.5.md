**Fixed**
- **The app keeps its notarization once it is out of the disk image.** Only the disk image was stapled, so the copy dragged into Applications — the only one anyone runs — carried no ticket of its own, and Gatekeeper had to ask Apple about it on first launch, which needs a working network. The app is now notarized and stapled by itself before the image is built around it, and the release checks the ticket on the copy that ships.
- **The disk image is signed.** Only the app inside it was, so `spctl` reported the download itself as having "no usable signature", even with a valid ticket stapled to it.

**Developer**
- **Running the tests no longer touches your settings.** The tests run inside Barkeep, so a test run started all of it. That re-saved the remembered Brewfile location, or forgot it if it no longer resolved, and also parsed that Brewfile and checked for updates. Now a test run starts the app with no window, and a test's settings go to a scratch store in the temporary folder.
- The tests run in CI.
- `release.sh` refuses a version that goes backwards. It checks the shared `notarytool` keychain profile before building, and says when a locked screen rather than a missing profile stops notarization. A failed or interrupted run cleans up after itself.
