**Fixed**
- **mrk mode shows each description, section and reason as mrk wrote it.** mrk's `sync --check` escapes a tab as `\t`, a newline as `\n` and a backslash as `\\` in each field. Barkeep showed the escapes as text, so a backslash in a description showed twice. It now undoes them, as Dipstick and `mrk-status` do.
- **A description that ends in a carriage return no longer hides the next package.** Barkeep split sync's output into lines by Swift Character, and a carriage return and the newline after it are one Character. That line and the next became one, and the next add or prune was missing from the Untracked lists. Barkeep now splits at every newline.
