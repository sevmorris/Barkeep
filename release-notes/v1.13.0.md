**Added**
- **Uninstall asks what to do with the Brewfile entry.** In the Brewfile view, Uninstall now asks whether to remove the package's entry from the Brewfile too, or keep it so `brew bundle` installs the package again. Before, it always kept the entry, and removing it took a second step. An entry goes only when brew actually uninstalled the package, so a failed uninstall leaves the Brewfile as it was. This works for one package or a selection.

**Changed**
- **A cask you add matches the rest of the Brewfile.** When most of the Brewfile's casks carry `greedy: true`, a cask Barkeep adds gets it too, so `brew upgrade` keeps it current like the others. A Brewfile whose casks don't use it still gets a bare line. mrk's Brewfile puts it on every cask, and before this each cask Barkeep added was the odd one out.
