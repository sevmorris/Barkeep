- **An add or a prune in mrk mode reaches GitHub without mrk-push.** mrk from 2026-10-29 has `sync --push` ([sevmorris/mrk#145](https://github.com/sevmorris/mrk/pull/145)): it commits the Brewfile and the description table, and no other file, and pushes that commit when it is the one commit that GitHub does not have. In mrk mode, Add to Brewfile, Adopt, and Remove from Brewfile on a package that is not installed now pass it while **Commit and Push Brewfile Changes**, in the File menu, is on, as it is at first. When sync keeps the commit, because an earlier commit is not pushed or the push fails, the console says why, and `mrk-push` pushes it. Barkeep's other edits to the Brewfile are not committed. With an mrk whose sync does not take `--push`, Barkeep runs sync as 1.15.2 does.
