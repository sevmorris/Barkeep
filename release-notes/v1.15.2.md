**Changed**
- **mrk mode asks mrk which options its scripts take.** mrk from 2026-10-29 has `scripts/mrk-contract` ([sevmorris/mrk#140](https://github.com/sevmorris/mrk/pull/140)), which lists, as JSON, the options of each script that Barkeep runs. Barkeep reads it once for each checkout, and again when the file changes, before it runs `sync` or `check-picker-desc`. When a script does not take an option, Barkeep runs nothing and says that this mrk is older than Barkeep, with `make pull`; or, for a contract of a later version, that this Barkeep is older ([sevmorris/mrk audit 22](https://github.com/sevmorris/mrk/blob/main/audit/22-audit-2026-10-28.md), O-2). With an mrk from before the command, Barkeep runs the script as before.

**Fixed**
- **A refusal shows sync's reason.** When sync refused a command line, the alert showed the last line it wrote, "Run sync --help for the options.", and not why. It now shows the line that sync marks ✗.

**Developer**
- `BarkeepTests/Fixtures/mrk-contract.json` is the output of mrk's `scripts/mrk-contract` from sevmorris/mrk#140, which added it. A test requires that it takes every command Barkeep runs.
