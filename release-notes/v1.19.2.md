Barkeep now shows updates for casks whose apps update themselves.

**Fixed**
- **An update for a greedy cask shows.** Homebrew lists a cask whose app updates itself, such as NordVPN or the Google Cloud CLI, as outdated only when asked with `--greedy`. Barkeep didn't ask that way, so a Brewfile line with `greedy: true`, which `brew upgrade` and `brew bundle` do upgrade, showed no update in the list, the toolbar's count or the details. Dipstick, which asks greedily, listed them. A cask without `greedy: true` is still left to update itself and shows an update only when Homebrew lists it without `--greedy`.
- **A formula and a cask with the same name are told apart** when Barkeep marks what is outdated.

**Developer**
- `BrewOutdated` decides which Brewfile entries are outdated from `brew outdated --json=v2`, run plain and with `--greedy`, with tests.
